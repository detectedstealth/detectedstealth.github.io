# Bruce Wade — Systems Engineer • Simulation & Tools • Founder

A modern, high-performance personal website and systems engineering showcase built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

The design aesthetic blends **Enterprise Credibility** with an **Edgy Cybernetic HUD** visual language, highlighting Bruce Wade's 15+ years across **Physical AI**, **NVIDIA Isaac Sim & OpenUSD**, **Unreal Engine C++**, **Authoring 12 Technical Books**, and **Scalable Cloud Infrastructure**.

---

## ⚡ Core Sections & Feature Highlights

1. **System Telemetry Navigation Bar**:
   - Live Vancouver (PST) UTC-7 digital clock.
   - Interactive system status pill (`ONLINE // AVAILABILITY OPEN`).
   - Quick launcher for the interactive developer terminal.

2. **Hero Diagnostic HUD**:
   - High-impact positioning for Physical AI, NVIDIA Isaac Sim, and Unreal C++ engines.
   - Live simulated FPS counter and multi-channel telemetry tabs.
   - Quick direct contact copy triggers.

3. **About & Systems Architecture Philosophy**:
   - Deep narrative on engineering determinism in simulation.
   - Interactive 4 Core Pillars: *Physical AI & Robotics Simulation*, *Game Engine Internals & C++*, *OpenUSD & Pipeline Automation*, and *Scalable Enterprise Cloud Infrastructure*.
   - Visual data pipeline topology diagram.

4. **Interactive Simulation Lab (Physical AI / Isaac Sim Sandbox)**:
   - Live interactive sandbox allowing users to adjust *Dome Lighting Lux*, *Gaussian Sensor Noise*, *Domain Variance*, and *PhysX Friction*.
   - Dynamic SVG rendering of robotic arm and 3D bounding box detection with live confidence calculation.
   - Real-time generated Python OpenUSD / Replicator code preview and simulated telemetry log stream.

5. **Career Journey (Comprehensive Chronology)**:
   - Complete career milestone cards from *Warply Designed Inc.* (2012–Present), *Theory Studios*, *CG Pro*, *Salesforce*, *Apress*, *Dibiup*, *Recruitology*, *ventureLab*, *YouAdWorld*, through foundational C++ game development.
   - Filterable by domain (*Simulation & Physical AI*, *Engine & Graphics*, *Enterprise Scale*, *Authoring*).
   - Expandable milestone details, technical deliverables, and tech stack tags.

6. **Portfolio & Architecture Blueprints**:
   - Featured projects with metrics, engineering solutions, and interactive "Inspect Blueprint" modals.
   - Venture spotlights on *Warply Designed Inc.*.

7. **Capabilities, Verified Credentials & Education**:
   - Interactive skill competency visualizer.
   - Verified certifications (*Helix Core Virtual Production*, *Unreal ICVFX*, *Vertex School*, *Indian Motorcycle Maintenance & Systems*, *Complete SQL Bootcamp*).
   - Academic history (*CG Pro*, *Vertex School*, *Art Institute of Vancouver VGP*, *DeVry University BS CIS*).

8. **Interactive Developer CLI Terminal**:
   - Built-in terminal emulator triggered via the navbar, header, or by pressing `` ` `` (backtick) / `~`.
   - Supports runnable commands: `help`, `about`, `skills`, `journey`, `projects`, `books`, `sim`, `contact`, `matrix`, `sudo`, `clear`.

9. **Direct Engagement Hub & Dispatcher**:
   - Interactive message protocol generator with email client integration and visual feedback.
   - Direct connection links to Email, LinkedIn, Warply Designed.

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start local Next.js server
npm run dev

# Build production bundle
npm run build

# Start production server
npm start
```

Runs on [http://localhost:3000](http://localhost:3000).
